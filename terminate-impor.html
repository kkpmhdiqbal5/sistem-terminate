📥 Tempel laporan Terminate (otomatis ke sheet sesuai)
Format "LAPORAN HARIAN TERMINATE" atau "Nama : … CID : …". Hanya POP / OLT Perbaungan dan Pantai Cermin. Diambil → sudah diambil, tidak ada di rumah → kunjungan, lanjut → lanjut berlanganan. Sama dengan yang dibaca otomatis dari grup.
💬 Impor Data dari WhatsApp Khusus Admin
Di WhatsApp: buka grup → ⋮ → Lainnya → Ekspor chat → Tanpa media. Pilih file .zip atau .txt hasil ekspor di bawah. Foto tidak diambil, hanya teks.
